Personal website and static resume.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Personal website (open in browser or deploy to GitHub Pages) |
| `site.css` | Styles for the website |
| `image.png` | Profile photo (optional) |
| `New_shinchan.mp4` | Hero background video (optional) |
| `resume_static.html` | Plain printable resume (self-contained, no external CSS) |

## View locally

```bash
open index.html
# or
python3 -m http.server 8000
# then visit http://localhost:8000/
```

Resume only: open `resume_static.html`.
